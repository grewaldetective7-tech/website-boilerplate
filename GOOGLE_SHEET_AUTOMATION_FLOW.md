# Google Sheet → Make → WhatsApp → AppSheet System

## Flow Overview
Google Sheet acts as central data source.
Make handles automation.
WhatsApp sends alerts.
AppSheet provides mobile interface.

## Step 1: Google Sheet
- Maintain client + patrol data
- Keep columns structured

## Step 2: Make Automation
- Trigger: Watch Rows (Google Sheets)
- Action: Router (conditions)
- Output: WhatsApp संदेश

## Step 3: WhatsApp API
- Send alerts for:
  - Emergency
  - Pending payments

## Step 4: AppSheet
- Convert sheet into mobile app
- Real-time sync enabled

## Result
Fully automated live system running 24/7.
